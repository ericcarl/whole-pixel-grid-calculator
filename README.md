# WholePixelGridCalculator™

[WholePixelGridCalculator™](https://www.wholepixelgridcalculator.com) is a design tool for creating grids that use whole numbers for all properties. Input your known values, such as the total grid width or number of columns, then explore possible values for gutters and margins. Choose between automatic or fixed column widths as desired. Undo is supported and useful.
